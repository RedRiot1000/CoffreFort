# CoffreFort

Gestionnaire de mots de passe local et chiffré (AES-256-GCM + Argon2id), pour Windows,
avec extension pour Brave, Opera GX, Chrome et Edge. Tes mots de passe restent sur ton PC :
rien n'est envoyé sur Internet. Seules les mises à jour du programme sont téléchargées
ici, et elles sont vérifiées par signature avant d'être installées.

## Installation

1. En haut de cette page : **Code → Download ZIP**, puis extrais le zip.
2. Double-clique sur **Installer CoffreFort.bat**.
   Si Windows affiche « Windows a protégé votre ordinateur » : *Informations complémentaires → Exécuter quand même*.
   L'installateur installe Python si besoin, place CoffreFort dans ton profil et crée un raccourci sur le bureau.
3. Pour l'extension, suis les 3 étapes affichées à la fin de l'installation.

Ensuite, CoffreFort se met à jour tout seul à chaque lancement.
Le mode d'emploi complet est dans [LISEZMOI.md](LISEZMOI.md).
